      Kết nối TikTok LIVE
      Gõ ID kênh TikTok đang phát Live. Trạng thái kết nối sẽ được cập nhật tức thì không cần tải lại trang.
      ⚙️ Cài đặt kết nối nâng cao (EulerStream API Key / Session ID)
      Lưu ý về lỗi EulerStream: Nếu TikTok hoặc Euler báo lỗi Failed to sign a request: This endpoint requires a Business plan, do EulerStream hạn chế gói ký miễn phí. Bạn có thể:
      • Đăng ký API Key miễn phí tại eulerstream.com rồi nhập vào ô dưới.
      • Hoặc dán mã Cookie sessionid của bạn (lấy từ F12 TikTok Web) để kết nối trực tiếp không qua Euler.
      • Hoặc chuyển sang tab 🎮 Bắn Test & Giả Lập trên menu để test đầy đủ hiệu ứng ngay lập tức!
